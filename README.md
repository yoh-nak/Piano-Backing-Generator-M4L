# Piano Backing Generator for Ableton Live

**Piano Backing Generator** is a Max for Live MIDI effect designed to generate expressive piano accompaniment patterns directly inside Ableton Live.

It transforms MIDI chord input into piano-style backing performances, including chord comping, arpeggios, rhythmic accompaniment, bass movement, and expressive left- and right-hand patterns.

The device is designed to work with your preferred piano VST, Kontakt instrument, Ableton Live instrument, or other MIDI-compatible sound source.

## Versions

- **v1.0** — Original Piano Backing Generator.
- **v2.0** — Expanded edition with 2,600 presets, advanced performance controls, improved accompaniment generation, and MIDI export.

- 2,600 presets covering 26 musical genres

## Independent Left and Right Hands

The device provides separate performance controls for the left and right hands.

Available controls include:

- Hand role and voice distribution
- Accompaniment pattern
- Note rate
- Register
- Note direction and order
- Dynamics
- Touch and articulation
- Timing offset
- Rhythmic density
- Syncopation
- Rhythm pattern

This allows different accompaniment roles to be combined, such as a steady left-hand bass pattern with expressive right-hand chords or arpeggios.

## MIDI Input and Recording

Piano Backing Generator supports two main input workflows:

**MIDI Keyboard**

Play chords from a MIDI keyboard and generate accompaniment in real time.

**MIDI Clip**

Use MIDI material from Ableton Live to generate piano accompaniment patterns.

Recording controls include:

- RECORD
- STOP
- WRITE CLIP
- NEW TAKE
- APPEND TAKE

The built-in piano roll displays recorded or generated MIDI notes together with available controller information.

## MIDI Export / CC / Pitch Bend / Aftertouch

The device supports MIDI recording and export of:

- MIDI notes and velocity
- MIDI Control Change (CC)
- Pitch Bend
- Channel Aftertouch
- Polyphonic Aftertouch

**Important:**

WRITE CLIP, NEW TAKE, and APPEND TAKE are primarily intended for writing MIDI note data into Ableton Live.

To preserve CC, Pitch Bend, and Aftertouch information, use **EXPORT MIDI** and import the exported `.mid` file into Ableton Live.

The MIDI export contains the controller data recorded or generated by the device. Existing automation from a source MIDI clip is not automatically imported into the device.

## Chord Voicing

Piano Backing Generator is primarily an accompaniment and performance generator.

For greater control over the chord structure, inversions, note distribution, and voicing, prepare your MIDI chords before sending them into the device.

You can use a separate MIDI chord tool, such as **Chord Voicing Writer**, to create or modify chord voicings before generating accompaniment.

## How to Use

1. Add Piano Backing Generator to a MIDI track in Ableton Live.
2. Place your preferred piano instrument after the device.
3. Select the MIDI input mode.
4. Choose a genre and preset.
5. Play or provide MIDI chords.
6. Adjust left/right-hand performance parameters as needed.
7. Record the generated performance.
8. Use WRITE CLIP, NEW TAKE, APPEND TAKE, or EXPORT MIDI to save the result.

## Installation

1. Download `Piano_Backing_Generator_v2.0.amxd`.
2. Open Ableton Live with Max for Live support.
3. Drag the `.amxd` file onto a MIDI track.
4. Place a MIDI-compatible piano instrument after the device.
5. Start generating accompaniment.

No additional external device files are required.
